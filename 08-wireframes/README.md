# Wireframes

Low fidelity wireframes (greyscale, layout and behaviour only) on a design canvas:
https://claude.ai/artifact/LdwZTVUy7GwAeKdx1ZVvgP

The canvas is private until it is shared from its Share menu.

## Games app (Project A)

| ID | Screen |
|---|---|
| G1 | Stall screen, idle: Spin the Wheel and Lucky Dip logos (uploaded in Admin, loaded from the API), session, prizes left |
| G2 | Stall screen states: reserved, spinning, Lucky Dip in progress, prize won, no prize, session ended |
| G3 | Mobile, Spin the Wheel: signing in, ready, spinning, you won (reference ID), prize collected |
| G4 | Mobile, Lucky Dip: ready, pick a box, opening, you won |
| G5 | Mobile warnings and errors: already played this session, other game in the same session, session ended, no session open, game in progress, turn timed out, scan the logo again, something went wrong |
